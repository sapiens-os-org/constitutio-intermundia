# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately.

1. Prefer a **confidential issue** on GitLab: https://gitlab.com/sapiens-os/constitutio-intermundia/-/issues/new (tick "This issue is confidential").
2. Or use the project's contact page: https://sapiensos.org/contribute/

Do not open a public issue for security reports.
