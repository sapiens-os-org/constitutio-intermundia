# Changelog

Public versions of *Sapiens OS · Constitutio Intermundia*. The text names no calendar date. Headings here follow the version in the file.

## 1.12.3 — 2026-11-06

- The public name is now Sapiens OS. The combined title is Sapiens OS · Constitutio Intermundia (middle dot). In the current text, Sapiens Novus and Sapiens Novus OS are written Sapiens OS. Constitutio Intermundia is unchanged. Homo Novus, Lingua Novus, and Axiom OS are unchanged.
- Axioms unchanged; no number, weight or formula changed.

## 1.12.2 — 2026-11-05

- II. Prime Directive: the third question now asks whether an act minimizes entropy and the free-rider while maximizing human flourishing.
- IX.1 Master Formula: the season is read as useful work minus entropy and free-riding.
- V.31 Traditio: Vigil prunes what failed, and adds a proven line.
- V.2 Educational Curriculum: the household rules are one neutral Household rule.
- IV.22 Cursus and VIII.15 Rete: the operating system is named Sapiens Novus OS.
- Axioms unchanged; no number, weight or formula changed.

## 1.12.1 — 2026-11-05

- V.31 Traditio, LEX 74AV now reads: What failed is pruned. The drill stays. Same meaning; no other text changed; axioms unchanged.

## 1.12 — 2026-11-05

- Version line set to **Public Release v1.12**. `date-released` in `CITATION.cff` is 2026-11-05.
- Spelling: ÆGIS is now written AEGIS throughout. ÆTHER keeps the Æ.
- Lex tags for Department VI use the code AEG, replacing ÆG.
- Lex tags are numbered 1..N straight through each chapter and no longer restart in each room, for example LEX 1ÆT to LEX 67ÆT in ÆTHER. The Glossary GL tags run 1..9 the same way. The front sections Praefatio, Heritas, and Alpha keep their own short runs. The text of every Lex line is unchanged.
- LEX 2GL describes the new tag format: a number plus a letter code, numbered 1..N inside each chapter.
- The twelve axioms are unchanged. No meaning, number, weight, formula, heading, or status line changed.
